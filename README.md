# RAG-Based Chatbot using Gemini and LangChain

This project implements a Retrieval-Augmented Generation RAG based chatbot using Streamlit, Google Gemini, LangChain, and FAISS.
It enables users to upload PDF documents and ask context-aware questions, retrieving relevant information from the document and generating accurate responses using a large language model.

🚀 Features

Upload and process PDF documents

Context-aware question answering using RAG architecture

Google Gemini LLM integration

FAISS vector database for efficient similarity search

Recursive text chunking for improved retrieval accuracy

Interactive chat interface with conversation flow

Streamlit-based user interface
